欢迎来到 My MkDocs Site¶

这是一个使用 MkDocs 构建的演示站点，展示了如何创建一个完整的文档网站。

🌟 站点特点¶

  • 简单易用: 使用 Markdown 编写内容，无需复杂的 HTML 知识
  • 响应式设计: 自动适配各种屏幕尺寸
  • 丰富的主题: 支持多种主题和自定义配置
  • 强大的扩展: 支持各种 Markdown 扩展和插件

📁 站点结构¶

  • 首页: 欢迎信息和站点概览
  • 关于: 关于本站点的更多信息
  • 文档: 使用指南和详细文档
  • 博客: 最新的文章和动态

🚀 快速开始¶

安装 MkDocs¶

pip install mkdocs

创建新站点¶

mkdocs new my-site
cd my-site

启动开发服务器¶

mkdocs serve

访问 http://localhost:8000 查看站点效果。

构建站点¶

mkdocs build
